# California housing through the cycles

An offline-capable interactive dashboard comparing the S.F. Bay Area, Greater LA,
Inland Empire, and California overall from 1990 through September 2026.

Open index.html, or view the GitHub Pages website. No build or server is required.
Includes nominal and inflation-adjusted prices, mortgage rates, indexed growth,
drawdowns, recession shading, and downloadable PNG/SVG charts and CSV data.

Sources and calculations are documented in the dashboard footer. Home prices
come from a supplied regional median-price CSV; external series are BLS CPI-U,
Freddie Mac mortgage rates, and the NBER recession indicator via FRED.
Greater LA includes Inland Empire. Monthly sale medians are not repeat-sales indexes.

This repository contains public website assets only. Data is a fixed snapshot;
future updates require republishing. GitHub Pages serves the root of the main branch.
